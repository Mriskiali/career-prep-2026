## PROYEK MACHINE LEARNING

**Klasifikasi Tumor Otak MRI — Hybrid Autoencoder + CNN** | 2025
*TensorFlow, Keras, OpenCV, Computer Vision, CRISP-DM*
- Membangun model hibrida **Autoencoder + CNN** untuk klasifikasi 4 kelas (glioma, meningioma, pituitary, no tumor) pada dataset publik **7.022 citra MRI**.
- Mencapai **akurasi uji 95%** (precision/recall/F1 rata-rata 0.95); Autoencoder merekonstruksi citra dengan **MSE 0.00135** dan **SSIM 0.93** untuk deteksi anomali berbasis error rekonstruksi.
- Menerapkan **CRISP-DM end-to-end**: preprocessing (grayscale, resize 128×128, normalisasi, optimasi **CLAHE** untuk kontras), pelatihan di Google Colab (T4 GPU), evaluasi confusion matrix.
- Men-deploy model sebagai **web service publik** (Flask di Railway + Streamlit dengan attention heatmap) — inferensi real-time dari upload citra MRI.
- **Notebook training publik** di Kaggle (GPU T4): kaggle.com/code/riskiali/skripsi-brain-tumor-mri-classification
